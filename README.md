# Prompt Hacking

Repositorio del training "Prompt Hacking: Técnicas ofensivas y defensivas en la era de la IA" de la Ekoparty.

## Cómo renderizar las slides

Las slides están hechas para [Marp](https://marp.app/):

```bash
npx @marp-team/marp-cli@latest --html -s .
```

Luego acceder a http://localhost:8080
